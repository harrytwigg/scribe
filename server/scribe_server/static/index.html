      The Chrome extension transcribes a Google Meet call, or any browser tab, with no bot in the call. Chrome only keeps an extension loaded from a folder that stays where it is, so this is how to put it back, in each Chrome profile that should have it.

      1. Download scribe-extension.zip and unzip it somewhere permanent (not Downloads or a temporary folder).
      2. In Chrome open chrome://extensions, turn on Developer mode, press Load unpacked and pick the unzipped folder.
      3. Open the extension's Settings: set the server to , paste the API token, enter your name, and press Allow microphone once.

      Repeat for each Chrome profile. Moving or deleting the folder removes the extension from Chrome the next time it starts.
